# DualSub

> 打开视频，字幕跟上。跨平台桌面播放器，实时双语字幕，全离线运行。

## 一句话

对标 [Transub-Player](https://github.com/dlsandy/Transub-Player)（Windows/WPF），我们做 **Tauri 跨平台版**：本地视频丢进来 → whisper.cpp 实时生成源语言字幕 → llama.cpp 本地翻译 → 原文 / 译文 / 双语三模式随时切换。模型下载完成后**全程离线**。

## 核心特性（规划）

- **实时字幕**：打开即播，字幕边看边生成，进度可见不卡死
- **三模式一键切换**：译文（看剧）/ 原文（对照）/ 双语（学习），快捷键 `1 / 2 / 3`
- **混合翻译**：在线免费翻译默认优先（快、零算力）；被内容过滤或断网时，一键下载本地模型（~4GB 按需）落回**全离线、无屏蔽**兜底
- **安装包轻量**：模型不内置，安装包仅几十 MB，按需下载
- **跨平台**：Windows / macOS / Linux 三端一个代码库
- **现成字幕优先**：视频同目录有字幕文件时直接加载，实时字幕随时可切回
