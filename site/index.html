干净的退出

工作原理

识别是软实时：领先播放太多自动等待，seek 直接丢弃当前窗口重启管线

实时识别

ffmpeg 管道持续抽取音频 → 静音检测过滤 → whisper（whisper.cpp GGML）逐窗推理，时间戳与画面精确对齐。

智能翻译

字幕按 3–5 句攒批送翻译：在线免费端点优先，混元 MT-7B 本地模型兜底；带持久缓存，回看零开销。

字幕上屏

译文到达前原文先显示，译文平滑替换。双语上下排布、字号描边可调，全部 DOM 渲染不糊画面。

安装

从 GitHub Releases 下载对应平台的安装包

macOS：首次打开提示「无法验证开发者」

应用未做付费签名公证（个人免费项目）。首次打开：右键 → 打开 → 再点打开（只需一次）；或终端执行 xattr -cr /Applications/DualSub.app。之后双击正常使用。

首次启动要下载什么？

首次使用向导会引导下载语音识别模型（~466MB，small 均衡档，也可选 base 快速档）。在线翻译开箱即用；想要全离线/无屏蔽的本地翻译，可再下载混元 MT-7B 模型（~4.4GB，断点续传）。

Windows / Linux 版呢？

安装包已可构建（CI 每次提交自动验证），播放内核接入中——先下载仅能体验界面。关注 Releases 获取更新。

和找现成字幕比，体验差在哪？

实时字幕是「能看懂、跟得上」级别：偶尔晚半拍、专有名词可能不准。有现成字幕时请优先用现成的——播放器会自动加载。

常见问题

更多细节见仓库内的技术方案文档

在线翻译被内容过滤了怎么办？

这正是本地模型存在的意义：设置页一键下载混元 MT-7B（~4.4GB），翻译完全在本地进行，离线可用、无任何内容屏蔽。

为什么安装包这么小？

识别与翻译模型加起来好几个 GB，打包进去只会劝退下载。我们只带运行时（~30MB），模型按需拉取、支持断点续传。

会采集我的数据吗？

识别永远在本地。使用在线翻译时，字幕文本会发送给翻译服务——介意的话切到「仅本地模型」引擎，全程断网也能用。
