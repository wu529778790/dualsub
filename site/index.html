安装

macOS（Apple Silicon）：三种方式任选，装完双击即开

方式一：一键脚本（推荐）

终端执行 curl -fsSL https://raw.githubusercontent.com/wu529778790/livesub-player/main/install.sh | bash。命令行下载不带隔离标记，安装完直接打开，无任何提示。指定版本：| bash -s -- v0.2.2。

方式二：Homebrew

brew tap wu529778790/tap https://github.com/wu529778790/homebrew-tap && brew install --cask livesub-player。之后 brew upgrade --cask livesub-player 跟版本走。

方式三：手动下载

从 Releases 下载 *-macOS.zip 解压，拖进「应用程序」。浏览器下载带隔离标记，首次打开：右键 → 打开 → 再点打开（只需一次）；或终端执行 xattr -cr /Applications/LiveSub-Player.app。

首次启动要下载什么？

首次使用向导会引导下载语音识别模型（~466MB，small 均衡档，也可选 base 快速档）。在线翻译开箱即用；想要全离线/无屏蔽的本地翻译，可再下载混元 MT-7B 模型（~4.4GB，断点续传）。

Windows / Linux 版呢？

安装包已可构建（CI 每次提交自动验证），播放内核接入中——先下载仅能体验界面。关注 Releases 获取更新。

和找现成字幕比，体验差在哪？

实时字幕是「能看懂、跟得上」级别：偶尔晚半拍、专有名词可能不准。有现成字幕时请优先用现成的——播放器会自动加载。

常见问题

更多细节见仓库内的技术方案文档

在线翻译被内容过滤了怎么办？

这正是本地模型存在的意义：设置页一键下载混元 MT-7B（~4.4GB），翻译完全在本地进行，离线可用、无任何内容屏蔽。

为什么安装包这么小？

识别与翻译模型加起来好几个 GB，打包进去只会劝退下载。我们只带运行时（~30MB），模型按需拉取、支持断点续传。

会采集我的数据吗？

识别永远在本地。使用在线翻译时，字幕文本会发送给翻译服务——介意的话切到「仅本地模型」引擎，全程断网也能用。
